### Overview

Seyi Inventory System is a production-grade full-stack web application that combines an e-commerce storefront with a powerful internal management console. Customers can browse products, manage their cart and place orders with email receipts. Staff members get a role-based admin dashboard to manage inventory, track stock movements, oversee orders and control user permisssions.
